# Resources

A curated collection of resources for learning idiomatic Rust, organized by category.

## Official Resources

### Documentation
- [The Rust Programming Language](https://doc.rust-lang.org/book/) - The official Rust book
- [Rust by Example](https://doc.rust-lang.org/rust-by-example/) - Learn Rust through examples
- [The Rust Reference](https://doc.rust-lang.org/reference/) - Language reference
- [The Rustonomicon](https://doc.rust-lang.org/nomicon/) - The dark arts of unsafe Rust
- [Rust API Guidelines](https://rust-lang.github.io/api-guidelines/) - Official API design guidelines

### Tools
- [Clippy](https://github.com/rust-lang/rust-clippy) - The official Rust linter (500+ lints)
- [rustfmt](https://github.com/rust-lang/rustfmt) - The official Rust formatter
- [rust-analyzer](https://rust-analyzer.github.io/) - IDE support for Rust

## Quick Reference

- [cheats.rs](https://cheats.rs/) - Comprehensive Rust cheat sheet
- [Rust Container Cheat Sheet](https://docs.google.com/presentation/d/1q-c7UAyrUlM-eZyTo1pd8SZ0qwA_wYxmPZVOQkoDmH4/) - Visual guide to collections
- [Rust String Conversions](https://nicholasbishop.github.io/rust-conversions/) - String type conversions
- [Rust Iterator Cheat Sheet](https://danielkeep.github.io/itercheat_baked.html) - Iterator methods reference

## Books

### For Learning
- [Programming Rust, 2nd Edition](https://www.oreilly.com/library/view/programming-rust-2nd/9781492052586/) - Comprehensive guide by Blandy, Orendorff, Tindall
- [Rust in Action](https://www.manning.com/books/rust-in-action) - Systems programming with Rust
- [Zero to Production in Rust](https://www.zero2prod.com/) - Building backends in Rust

### For Improving
- [Rust for Rustaceans](https://rust-for-rustaceans.com/) - Advanced idioms and techniques by Jon Gjengset
- [Rust Design Patterns](https://rust-unofficial.github.io/patterns/) - Common design patterns
- [The Rust Performance Book](https://nnethercote.github.io/perf-book/) - Performance optimization

### Specialized
- [Rust Atomics and Locks](https://marabos.nl/atomics/) - Concurrency primitives (free online)
- [Async Rust](https://rust-lang.github.io/async-book/) - Asynchronous programming
